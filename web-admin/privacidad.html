1. Qué información recogemos

Datos de la cuenta

  • Nombre y apellido
  • Usuario y contraseña (la contraseña se guarda cifrada, nunca en texto legible)
  • Correo electrónico y número de teléfono
  • Número de documento de identidad, cuando el taller lo registra
  • Rol asignado (administrador, mecánico o cliente)

Datos de vehículos y servicios

  • Marca, modelo, placa, color y año del vehículo
  • Estado de recepción: daños registrados, kilometraje, combustible, accesorios y documentos entregados
  • Firmas digitales del cliente y del recepcionista
  • Fotografías del vehículo y de los avances de reparación
  • Historial de servicios, montos y pagos

Ubicación

  • La aplicación solicita la ubicación únicamente cuando el usuario pulsa el botón de auxilio vial (SOS), para que el taller pueda localizar el vehículo averiado.
  • La ubicación no se recoge en segundo plano ni de forma continua.
  • El usuario puede negar el permiso y escribir la dirección manualmente.

Cámara y almacenamiento

  • La aplicación accede a la cámara y a la galería solo cuando el usuario decide adjuntar una fotografía a una recepción o a un avance de reparación.

2. Para qué usamos la información

  • Registrar el ingreso de vehículos y generar el acta de recepción
  • Dar seguimiento al estado de las reparaciones
  • Notificar al cliente sobre avances, trabajos terminados y próximos mantenimientos
  • Atender solicitudes de auxilio vial
  • Llevar el historial de servicios y pagos del taller
  • Registrar quién realiza cada acción dentro del sistema (auditoría interna)

No usamos los datos para publicidad ni para crear perfiles comerciales.

3. Con quién compartimos la información

No vendemos ni cedemos datos personales a terceros. La información se comparte únicamente en estos casos:

  • Dentro del taller: el administrador y el mecánico asignado ven los datos necesarios para atender el vehículo.
  • Proveedor de alojamiento: los datos se almacenan en servidores de nuestro proveedor de infraestructura, que actúa solo como custodio técnico.
  • Cuando el usuario lo decide: al compartir un acta o una ubicación por WhatsApp u otra aplicación, el envío lo realiza el propio usuario.
  • Obligación legal: si una autoridad competente lo requiere formalmente.

4. Cuánto tiempo conservamos los datos

Los datos del historial de servicios se conservan mientras la cuenta del taller esté activa, ya que constituyen el respaldo documental de los trabajos realizados. Si el taller cierra su cuenta, los datos se eliminan a solicitud del titular.

5. Seguridad

  • Toda la comunicación entre la aplicación y el servidor viaja cifrada (HTTPS)
  • Las contraseñas se almacenan con cifrado irreversible
  • El acceso está limitado por roles y permisos
  • Cada acción relevante queda registrada con usuario, fecha y dispositivo

Ningún sistema es completamente invulnerable; trabajamos para mantener medidas razonables y actualizadas de protección.

  • Corregir información inexacta
  • Eliminar tu cuenta y tus datos personales
  • Retirar el permiso de ubicación o cámara desde los ajustes del teléfono
